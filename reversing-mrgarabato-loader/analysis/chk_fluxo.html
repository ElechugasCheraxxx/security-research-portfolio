Términos y Condiciones de Uso

Al comprar, acceder o usar un producto digital de esta tienda, aceptas estas condiciones. Si no estás de acuerdo, no completes la compra ni utilices el producto.

1. Producto digital y entrega

  • Las licencias, autorizaciones o accesos son productos digitales.
  • La entrega puede realizarse por correo, sistema automático, cuenta o medio de contacto configurado.
  • No se entrega ningún producto físico.
  • Las credenciales o claves son personales, no transferibles y no deben compartirse.

2. Pagos, activación y evidencia

  • El pago debe completarse y validarse antes de activar o entregar el producto.
  • El sistema puede guardar evidencia de compra, entrega, correo, ID de cliente, método de pago, fecha, IP, identificadores técnicos y logs de operación.
  • Los precios pueden cambiar sin previo aviso antes de completar la compra.

3. Reembolsos y soporte

Un reembolso solo será evaluado si existe un fallo comprobable causado por el sistema de entrega o por un error directo de la tienda. El cliente debe contactar soporte, explicar el problema y permitir la revisión técnica.

No se aceptan reembolsos por cambio de opinión, uso incorrecto, incompatibilidad del equipo, problemas de internet, fallos de terceros, sanciones de cuentas externas, negarse a colaborar con soporte o no presentar evidencia suficiente.

4. Contracargos y disputas

Antes de abrir una disputa o contracargo, el cliente debe contactar soporte. Las disputas sin proceso de soporte pueden causar suspensión de licencia, bloqueo de cuenta y conservación de evidencia para responder al procesador de pago.

5. Restricciones de licencia

  • No puedes revender, compartir, filtrar, modificar, descompilar ni redistribuir el producto.
  • No puedes usar claves en más dispositivos o cuentas de los permitidos.
  • La tienda puede suspender accesos ante actividad sospechosa, abuso, fraude o incumplimiento de estas condiciones.

6. Disponibilidad

No se garantiza disponibilidad permanente, compatibilidad indefinida ni actualizaciones continuas. Los productos pueden cambiar, pausarse o dejar de estar disponibles por mantenimiento, cambios técnicos o servicios de terceros.

Al marcar la casilla de aceptación y continuar con el pago, declaras que leíste, entendiste y aceptaste estos Términos y Condiciones.

Política de Privacidad

Esta política explica qué información puede recopilarse para procesar compras digitales, entregar productos, validar pagos y brindar soporte.

1. Datos que pueden recopilarse

  • Correo electrónico, ID de cliente y medio de contacto elegido.
  • Información del pedido: producto, duración, monto, moneda, fecha y método de pago.
  • Registros técnicos necesarios para seguridad: IP, user agent, logs de sesión, estado de entrega, validación de licencia y eventos antifraude.
  • Identificadores técnicos como HWID cuando sean necesarios para proteger licencias.

2. Uso de la información

  • Procesar pagos y entregar el producto.
  • Confirmar titularidad, resolver soporte y prevenir fraude.
  • Responder disputas o contracargos con evidencia de pago y entrega.
  • Mejorar seguridad, estabilidad y funcionamiento del sistema.

3. Procesadores externos

Los pagos pueden procesarse mediante servicios externos como billeteras, pasarelas o proveedores de pago. La tienda no controla sus políticas internas; cada proveedor puede tratar datos según sus propios términos.

4. Conservación y seguridad

Los datos se conservan el tiempo necesario para soporte, auditoría, prevención de fraude, cumplimiento operativo y defensa ante disputas. Se aplican medidas razonables para proteger la información.

5. Compartición de datos

No se vende información personal. Solo puede compartirse cuando sea necesario para procesar el pago, entregar el producto, cumplir obligaciones legales o responder disputas con el procesador de pago.

Al continuar con la compra, aceptas el tratamiento de datos necesario para completar la operación y recibir soporte.
